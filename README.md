# Introduction 
Project to manage, deploy AI agents for NLP2BI service.

# Getting Started
To get started with your local env

1. clone the repo(ensure your pwd is the root of the project)

2. Create a virtual env and activate it. This should install all the dependencies. (This is useful to manage multi-user dev env's to ensure dependencies are at parity).

3. This project uses `conda` to manage virual env and as package manager. if not installed follow this [document](https://docs.conda.io/projects/conda/en/stable/user-guide/install/windows.html) to install it.

4. Execute the commands to install dependencies and activate the virtual env
```
conda env create -f environment.yml

conda activate nlp_agent
```
